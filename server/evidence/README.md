# Deployment-owned source inventories

This directory is copied into the server build by `script/build.ts`. The public
source release includes this note so a source-only build has the expected
directory, but does not redistribute customer source-inventory JSON files.

Keep each deployment's existing verified inventory artifacts private. This note
is not evidence, a receipt, a signature, or a replacement for any inventory.
Source-manifest verification still requires the actual matching artifact.
